ForgetSite 隐私政策

生效日期：2026-11-17

概要

ForgetSite 是一个 Chrome 扩展，用于按域名定期删除 Chrome 浏览历史。 本扩展不运营任何服务器，不包含统计、广告或追踪代码，也不会把你的浏览历史、 标签页地址或设置上传到任何地方。所有数据仅在你的设备本地处理。

1. 本扩展访问的数据

1.1 浏览历史

当你配置了清理规则后，本扩展会通过 Chrome 的 history API 查询与规则域名匹配的历史记录（包括 URL、标题和访问时间），并删除这些记录。 查询和删除都在本地完成，不会上传任何历史数据。

1.2 当前标签页地址

当你打开扩展弹窗、使用右键菜单或按下快捷键时，本扩展会读取当前标签页的 URL， 以便识别并建议当前网站域名。本扩展不会读取页面内容、表单、密码或 Cookie。

1.3 设置

清理规则（域名、周期、上次清理时间、删除条数）保存在 chrome.storage.local 中，仅用于在本机展示和执行这些规则。

2. 数据的使用与共享

  • 仅用于实现本扩展的单一用途：按你设置的域名和周期删除浏览历史。
  • 不向任何服务器或第三方传输、出售、出租或共享数据。
  • 不将数据用于广告、用户画像、信用评估或任何与扩展功能无关的用途。
  • 不收集分析数据或崩溃报告。

3. 数据保留与删除

  • 历史记录：按规则周期删除；你也可以随时在弹窗或设置页手动清理。
  • 规则与设置：保留在本机，直到你删除规则或卸载扩展。卸载扩展会删除 chrome.storage.local 中的数据。
  • 本扩展没有服务端副本，因此不存在服务端数据保留。

4. 权限说明

  • history：查询并删除你配置的域名对应的浏览历史。
  • tabs：读取当前标签页 URL，用于一键加入当前网站。
  • storage：在本机保存清理规则。
  • alarms：每 5 分钟检查一次到期规则。
  • contextMenus：在页面右键菜单中提供加入清理列表的入口。

5. 你的控制

  • 在设置页添加、编辑、删除规则，或立即清理。
  • 在 chrome://extensions 中停用或卸载扩展。
  • 在 chrome://settings/syncSetup 中关闭“历史记录”同步， 以避免删除操作同步到同一账号的其他设备。

6. Chrome 同步说明

如果你开启了 Chrome 同步中的“历史记录”，通过 Chrome history API 执行的删除 可能会同步到同一账号的其他设备。这是 Chrome 自身的行为，与本扩展无关。

7. 儿童隐私

本扩展不面向 13 岁以下儿童，也不会有意收集儿童数据。

8. 政策变更

如果本政策发生变更，我们会更新本页面顶部的生效日期。

9. 联系方式

如有问题，请通过 GitHub Issues 联系。

English summary

ForgetSite deletes Chrome browsing history for domains you configure. It runs entirely on your device: there are no servers, no analytics, no ads, no tracking, and no transmission of browsing history, tab URLs, or settings. History is accessed only through Chrome's history API to find and delete entries matching your rules. Settings are stored in chrome.storage.local and are removed when you uninstall the extension.
